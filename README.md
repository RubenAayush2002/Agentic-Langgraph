# LangGraph Learning

A hands-on repository for learning and experimenting with **LangGraph** and building stateful AI agent workflows.

## Topics Covered

* StateGraph and graph fundamentals
* Nodes, edges, and state management
* Tool calling and ReAct agent graphs
* Graphs with memory
* Streaming responses
* Human-in-the-loop workflows
* Debugging and tracing
* Multimodal AI workflows
* Message handling and conversation history
* Building and experimenting with AI agents

## Goal

The goal of this repository is to understand how LangGraph works by building small examples and progressively exploring more advanced agentic workflows.

## Tech Stack

* Python
* LangGraph
* LangChain
* LLMs
* Tool Calling
* AI Agents

## Structure

Each example focuses on a specific LangGraph concept and is intended to be simple, practical, and easy to experiment with.
